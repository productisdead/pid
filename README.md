AI makes PRDs, roadmaps and status updates in seconds. The judgment behind them is still the job. Each skill here is one piece of product judgment, written down so an agent can apply it: Claude, Claude Code, ChatGPT, Cursor, or anything else that reads `SKILL.md` files.

## Skills

Every skill lives in its own folder under [`skills/`](skills) as a standard `SKILL.md`: PRD reviews, prioritization, product vision, metric trees, interview synthesis, UX audits and more.

Browse them with previews, filters and search at **[productisdead.com/skills](https://productisdead.com/skills)**. The same page lists recommended skills by other people, each with a note on why it's worth using.

To use one, open its page on the site (download plus a one-line install command) or grab its `SKILL.md` straight from GitHub.
